# โปสเตอร์ระบบลานิสิต

A2 แนวตั้ง 420 × 594 มม. ใช้ XeLaTeX และฟอนต์ Bai Jamjuree จาก `font/Bai_Jamjuree/` โดยตรง ไม่ต้องติดตั้งฟอนต์ใน Windows ฟอนต์จะฝังใน PDF

## สร้าง PDF

```powershell
./scripts/build.ps1
```

ผลลัพธ์คือ `poster-a2.pdf` ส่วนไฟล์ชั่วคราวอยู่ใน `build/` ใช้ VS Code กับ LaTeX Workshop ที่ตั้งค่าไว้เดิมได้

## ใส่ภาพ

นำภาพ PNG ใส่ใน `images/` ตามชื่อด้านล่างแล้วคอมไพล์ใหม่ ภาพจะแทนช่องว่างอัตโนมัติและรักษาสัดส่วน หากยังไม่มีภาพจะแสดงชื่อไฟล์ในกรอบ

| ไฟล์                 | เนื้อหา                                                                |
| -------------------- | ---------------------------------------------------------------------- |
| logo.png             | โลโก้มหาวิทยาลัย                                                       |
| architecture.png     | เว็บ บริการ ฐานใบลา ระบบข้อมูลสนับสนุน บริการภายนอก และ ETL/คลังข้อมูล |
| leave-flow.png       | Flow ยื่นและพิจารณา แยกการรับทราบของผู้สอนจากการอนุมัติ                |
| student-request.png  | แบบฟอร์มคำขอ เน้นประเภท วันที่ และรายวิชา                              |
| approval-flow.png    | ลำดับพิจารณาและสถานะ                                                   |
| advisor-review.png   | หน้าพิจารณาของที่ปรึกษา                                                |
| warehouse-report.png | รายงานพร้อมตัวกรองและหน่วยนับ                                          |

ใช้ข้อมูลทดสอบและ crop เฉพาะส่วนสำคัญ ปิดบังข้อมูลส่วนบุคคล ภาพหน้าจอกว้างประมาณ 85 มม. ควรมีความกว้างประมาณ 1000 พิกเซลสำหรับงานพิมพ์ 300 dpi

## ปรับข้อความ

แก้ใน `main.tex` และเติมชื่ออาจารย์ที่ปรึกษาก่อนส่ง ข้อความผลลัพธ์อธิบายผลตรวจโครงสร้าง ยังไม่ได้อ้างว่าทดสอบผ่านหรือประเมินผู้ใช้แล้ว ขนาดตัวอักษร: ชื่อไทย 36 pt อังกฤษ 23 pt หัวข้อ 27 pt เนื้อหา 19 pt คำบรรยาย 15 pt และข้อมูลสังกัด 16 pt

ตำแหน่งเป็นมิลลิเมตรจากมุมซ้ายบนของกระดาษ ปรับ `textblock` เมื่อเพิ่มข้อความมากกว่าพื้นที่เดิม ตรวจ PDF ทุกครั้งก่อนพิมพ์ และสั่งพิมพ์ขนาดจริง 100%

## รูปแบบตามตัวอย่าง

กรอบบางรอบหน้า โลโก้ซ้ายและชื่อเรื่องขวา เส้นแบ่งส่วนหัว เนื้อหาสองคอลัมน์ ฝั่งซ้ายเป็นบทคัดย่อ วัตถุประสงค์ ประโยชน์ที่คาดว่าจะได้รับ และภาพรวมระบบ ฝั่งขวาจัดภาพหกภาพสองคอลัมน์สามแถว ตามด้วยสรุปผล ข้อเสนอแนะ และช่องทางติดต่อ ใช้ข้อความสีดำและ Bai Jamjuree
