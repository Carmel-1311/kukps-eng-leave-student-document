\subsection{ปัญหาสำหรับผู้พัฒนา}
\begin{itemize}
  \item \code{DATABASE\_URL is required}: ตรวจ \code{apps/api/.env} และ working directory
  \item Web ได้ HTML แทน JSON: ตรวจ \code{API\_URL}, backend proxy และ API prefix
  \item API ตอบ 401: ตรวจ Bearer token อายุ token และบริการยืนยัน token
  \item ไม่พบ approval route: ตรวจ advisor, major/department, ผู้ดำรงตำแหน่ง และ account mapping
  \item รายงานไม่มีข้อมูล: ตรวจ URL ของฐานต้นทางและคลังข้อมูล ได้แก่

    \code{ETL\_SOURCE\_DATABASE\_URL} และ \code{WAREHOUSE\_V2\_DATABASE\_URL}

    จากนั้นตรวจ data-quality check และรอบ ETL
  \item เปิดหลักฐานไม่ได้: ตรวจ \code{BASE\_STORAGE\_PATH}, permission และชื่อไฟล์
  \item Prisma client ไม่ตรง schema: รัน \code{pnpm --filter api generate}
\end{itemize}

\subsection{ข้อมูลส่วนบุคคลและ Production Checklist}
ผู้ใช้ต้องเปิดดูเฉพาะคำร้องที่เกี่ยวข้อง ไม่ส่งต่อข้อมูลสุขภาพ ไม่เผยแพร่ screenshot ที่มีข้อมูลส่วนบุคคล และออกจากระบบเมื่อไม่ใช้งาน หากเห็นข้อมูลเกินสิทธิ์ต้องหยุดใช้งานส่วนนั้นและแจ้งผู้ดูแล

ก่อน production ต้องไม่ commit secrets, กำหนด public token secret, จำกัด database privilege และ CORS, ใช้ persistent storage พร้อม backup, ตรวจ authorization ของทุก write endpoint และจัดให้มี audit log, malware scanning, rate limiting, security headers, monitoring, automated tests และแผนกู้คืน
